# 🚇 부산 지하철역별 이용객 수 지도 분석 앱 (Busan Subway Map App)

파이썬과 Streamlit, Folium을 활용하여 부산 지하철 역별 이용객 수를 시각화하고 분석하는 웹 애플리케이션입니다.

---

## ✨ 주요 기능
1. **CSV 데이터 업로드**: 부산 지하철 데이터(`busan_subway.csv`)를 업로드하여 실시간으로 확인
2. **호선별 필터링**: `multiselect` 기능을 이용해 원하는 호선(1~4호선)만 골라서 지도와 표에 표시
3. **이용객 수 상위 5개 역**: 현재 필터링된 데이터 중 이용객이 가장 많은 상위 5개 역을 표로 제공
4. **시각화 지도 (Folium)**:
   - 부산 중심부 지도 위에 각 역의 위치를 원형 마커(`CircleMarker`)로 표시
   - 이용객 수에 비례하도록 원의 반지름을 제곱근(sqrt) 값으로 조절
   - 호선별로 마커 색상 구분 (1호선: 주황, 2호선: 초록, 3호선: 갈색, 4호선: 파랑)
   - 마우스 오버 시 역명 표시(Tooltip), 클릭 시 상세 이용객 수 팝업(Popup)

---

## 🛠️ 사용 기술 (Tech Stack)
- **Python**
- **Streamlit** (웹 프레임워크)
- **Pandas** (데이터 전처리)
- **Folium & Streamlit-Folium** (인터랙티브 지도 시각화)
